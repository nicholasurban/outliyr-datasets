# Outliyr Open Datasets

Instrument-measured health-tech performance data from [Outliyr](https://outliyr.com), the independent testing lab for biohacking and health-optimization gear.

Every dataset here is measured with professional instruments (spectroradiometer, EMF meters, flicker analysis) using the published [testing methodology](https://outliyr.com/light-therapy-testing-methodology). Claimed specs come from marketing; these numbers come from meters.

## Datasets

| Dataset | Contents | Status |
|---|---|---|
| [light-therapy-devices](light-therapy-devices/) | 76 devices: measured vs claimed irradiance, wavelengths, flicker, EMF, pricing | **Live** (interactive: [comparison database](https://outliyr.com/app/light-therapy-comparison)) |
| state-of-biohacking | Survey results: what biohackers actually practice, spend, and prioritize | Published separately: [report](https://outliyr.com/state-of-biohacking-and-longevity), [CSV](https://raw.githubusercontent.com/nicholasurban/state-of-biohacking-and-longevity/main/state-of-biohacking-and-longevity.csv), [GitHub](https://github.com/nicholasurban/state-of-biohacking-and-longevity), [DOI](https://doi.org/10.5281/zenodo.20320083) |
